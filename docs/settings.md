# ⚙️ Settings

[← Back to README](../README.md) · [Features](features.md) · [Usage](usage.md) · [Architecture](architecture.md)

A System Settings-style sidebar, grouped into **Capture**, **Meetings**, **Automation** (Digest + Integrations), **Privacy & Security**, **System**, and **Account** (Usage & Cost + About) — with **Essentials**, **General**, and **AI & Models** on top. The window opens on **Essentials** — a live first-run readiness checklist (Groq API key, Microphone, Accessibility) with a "you're all set" banner once the three requirements are met, a reminder of the current dictation gesture, and the notes-folder location; every row deep-links into the pane that owns the full controls. A **search field** at the top of the sidebar finds settings across every pane — matching the setting's label, its pane, and synonyms/keywords (e.g. "whisper" → transcription model, "reset"/"default" → any pane with an inline reset, "backup" → General). Results show as a flat list with each setting's icon and host pane; clicking jumps straight there.

| Group / Pane | Options (defaults in bold) |
| --- | --- |
| **Essentials** | A read-only landing dashboard (no stored settings of its own) — a three-step setup checklist with live status (Groq API key, Microphone, Accessibility), a banner that flips to "You're all set" when all three are granted, a one-line reminder of the active dictation gesture, and the notes-folder path. Each row jumps to the pane with the real controls (API key window, Permissions, Dictation, Notes & Summaries) |
| **General** | Notes — open notes in external editor (**off** — off uses the in-app rendered-Markdown viewer; on hands every note-open to your default `.md` app like VS Code / Obsidian); prefer built-in microphone (**off** — uses the system default input; turn on to keep AirPods in high-quality audio); date format for the menu & Catalog (**dd MMM yyyy** → 03 Jul 2026; presets + custom pattern with live preview); **PDF Export** — paper size for exported PDFs (notes, Reports, POCs): **US Letter** (default) or **A4**; start at login (**off** — registers as a macOS Login Item); **Backup** — back up notes + quick notes + dictations + Catalog to one `.zip`, or restore (merges into current folders); reset all settings |
| **AI & Models** | Groq account — API key status; **Models** — transcription model (**whisper-large-v3**); transcription language (**en**, ISO 639-1 — applies to dictation *and* meetings); polishing model (**meta-llama/llama-4-scout-17b-16e-instruct** — high daily/throughput limits; presets also include llama-3.3-70b-versatile, gpt-oss-120b/20b, qwen3-32b); lightweight-tasks model (**llama-3.1-8b-instant** — cheap/fast model for the live brief, agenda coverage, auto-tagging, and search-term expansion); **On-Device & Fallback** — offline fallback (**on** — Apple on-device recognition when Groq is unreachable, covering dictation, quick notes, and meetings); prefer on-device AI for summaries & drafts (**off** — generate note briefs, relationship digests, and follow-ups with Apple Intelligence instead of Groq while keeping Groq for transcription; falls back to Groq if the on-device model isn't available; shows availability status) |
| Capture · **Dictation** | Push-to-talk key (**Right Option**, or Left Option / Right Command / Right Control / Fn); activation (**Press to toggle** (default) — press once to start, again to stop, never held; **Hold to talk** — record while held; **Tap to lock (hybrid)** — hold for a quick phrase *or* tap once to latch hands-free, tap again or Esc to stop; the **tap-vs-hold threshold** (**0.4 s**) is adjustable when this mode is chosen); streaming dictation (**on**, chunk **10 s**); **Silence** — skip silent recordings (**on**) so a recording (or streaming chunk) with no speech is never uploaded to Groq (saves API calls + avoids Whisper hallucinating text from silence), with a **silence threshold** (**−45 dBFS**; lower uploads quieter speech, higher skips more); **Audio Import** — max import size (**50 MB**) for the menu's *Transcribe Audio File…* and Catalog audio drag-and-drop (transcribed into a meeting note, filed under the file's own date; wav/mp3/m4a/ogg/opus/flac/webm); accuracy — custom vocabulary + find→replace rules; recall — keep recent dictations for ⌃⌥V (**on**, keep **20**); archive — save each dictation to a file (**on**) with its own folder and organization (**year/month**) |
| Capture · **Writing Styles** | Voice commands (**on**) — each rule edited as a **phrase → effect** row (add/remove), with a collapsible bulk paste box; the polishing model follows them; writing styles (6 editable built-ins + your own custom styles, with a global default for unrecognized apps); per-app style overrides — edited as rows of a **bundle-ID field + built-in-style picker**, with an **Add app…** menu that lists your running apps so you don't have to hunt for bundle IDs (plus a bulk `bundle.id: style` paste box); browser tab styles (**on** — per-site rules edited as rows: a host text field + a **style picker** over the built-in and custom styles, add/remove, with a collapsible bulk `host: style` paste box; e.g. Gmail → Email) |
| Capture · **Quick Notes** | Save-to folder (**…/Notes/Quick Notes**); saved notification (**on**) |
| Meetings · **Recording** | Call detection — offer to start/stop with the call (**on**); overlay mode (**minimal pill** / live captions / hidden); caption fade delay (**6 s**); echo suppression (**on**, gate **0.4 s**); speakers — labels (**You** / **Them**) and voice diarization (**on**, experimental; max speakers **4**, separation sensitivity **1.0** — lower splits voices more eagerly, higher merges similar voices); **Live Assistance** — live brief (**on** — floating in-meeting assistant, cloud-only; default for the per-meeting **Show live brief** switch) with a **refresh interval** (**25 s** — longer = fewer AI calls / lower cost), and show prep card on start (**on** — floating panel of the linked org/project's recent notes; default for the per-meeting **Show prep card** switch); *Advanced (collapsed):* mic threshold (**−40 dBFS**), system-audio threshold (**−50 dBFS**), segment flush pause (**1.5 s**), max segment length (**25 s**), retry attempts (**3**), retry interval (**20 s**); **Detection & Timing** — auto-detect poll interval (**3 s**), meeting-end sensitivity (**2** quiet polls), transcription request timeout (**30 s**), audio-import request timeout (**120 s**), live-brief refresh threshold (**350 chars** of new speech), summary context budget (**24k chars** fed to AI summaries) |
| Meetings · **Notes & Summaries** | Notes folder (**~/Documents/Notes**); file organization (**year/month/day** / year/month / year / single folder); Obsidian front-matter (**on**); **Summary Content** — AI summary (**on**) and action items (**on**); **AI Extraction** (a separate group; each needs network and is skipped in Local-only mode) — structured extraction: decisions / risks / open questions (**on**); extract key fields per meeting type (**on** — pulls template-specific fields like a customer call's deal stage / budget / timeline / next step, a discovery call's primary need, or a solution demo's technical fit into a Key Details section and machine-readable front-matter; categorical fields are mirrored into tags so they're filterable in the Catalog); extract unanswered questions (**on** — adds an Unanswered Questions follow-up list; one extra AI call); topic chapters (**on**, one extra AI call/meeting); **Keyword Radar** — a watchlist (competitors, products, risk phrases) edited as removable **chips** (type a term + Return to add, ✕ to remove, Clear All, plus a collapsible bulk paste/edit box), scanned locally in every finished meeting, surfaced in a Mentions section and mirrored to tags (empty = off); auto-tag topics + entities into front-matter (**on**); saved notification (**on**); Catalog & Ask search depth (**200** recent meetings); action items from last (**10** meetings). *(The live brief and prep-card controls moved to the **Recording** pane, alongside the other during-the-meeting settings.)* |
| Meetings · **Meeting Templates** | The meeting-type template editor (split out of Notes & Summaries). Meeting template (**Customer Call**, 12 built-in types grouped into Sales & Customer / Delivery & Project / Team & Internal / Other, + your own custom templates — a one-line description under the picker, editable summary sections *and* the **Auto follow-up shape** for that meeting type, add/rename/delete). **Backup & Sharing** — export your custom meeting + draft templates and guidance edits to one `.json` bundle, or import with **Merge** / **Replace** (built-ins aren't exported) |
| Meetings · **Draft Templates** | Edit the drafting guidance behind each **output document type** offered by the note viewer's **Draft…** menu — 13 built-ins grouped into Email & Recap / Records / Sales / Reports / Retro (**Minutes of Meeting**, **Follow-up Email**, **Status Update**, **Executive Summary**, **Action-Item List**, **Thank-You Note**, **Quick Recap**, **Decision Log**, **Talking Points**, **Retrospective**, **FAQ**, **Proposal / Next Steps**, **POC Plan**) plus **your own custom document types** (**+** to add, editable name + guidance, **trash** to delete). Pick a type (a one-line description shows under the picker), edit its instruction (recipient, tone, sections, format); built-ins have a per-type **Reset to Default**. Changing the guidance regenerates that document on next draft (each type caches separately). Distinct from a *meeting* template's **Auto follow-up shape** (which adapts the "Auto — match meeting type" draft to the meeting type — including custom meeting templates — and is edited under Meeting Templates → follow-up guidance). Includes the shared **Backup & Sharing** export/import (one `.json` bundle covering meeting *and* document/email templates). A **Follow-Up Packet** section at the top is a pick-and-reorder list of the sections the note viewer's one-click packet assembles — any draft-document type can be added, removed, and moved up/down (order = order in the composed document); the default is **Follow-up Email → POC Plan → Action Items**, and those three keep their special grounding (meeting-type email, the linked project's criteria, the note's own checklist) wherever they sit. A counter notes each section is a separate AI call. Plus **Confirm before generating** (**on** — a one-time prompt before the packet fires its several cloud-AI calls, naming the configured sections; the dialog's "Don't ask again" clears it). |
| Automation · **Digest** | Proactive digest (**off**) — a scheduled rollup, **grouped by relationship**, of recent meetings, open/overdue action items, and quiet relationships, shown in an interactive window and archived as a note. Frequency (**daily** / weekly + weekday / monthly [1st] / yearly [1 Jan]); time of day (**9 AM**); flag relationships quiet after (**30 days**). Schedule controls stay visible but disabled until enabled. Build one anytime from the menu → Today's Digest… |
| Privacy & Security · **Privacy** | Local-only mode (**off** — on-device only, no network; transcription via Apple Speech, and summaries/briefs/follow-ups via Apple Intelligence with topic/entity tags via NaturalLanguage, all on-device — shows Apple Intelligence availability); redact sensitive info (**off**) with per-category toggles for emails, phones, and long number sequences |
| Privacy & Security · **Permissions** | Live status of Microphone, System Audio Recording, Accessibility, Automation (default browser, optional), and Reminders (action-item export, optional) with shortcuts to the relevant Settings panes, plus Reset All Permissions |
| System · **Shortcuts** | Reference card of all global shortcuts (push-to-talk, Esc, ⌃⌥V, ⌃⌥J, ⌃⌥M / ⌃⌥P / ⌃⌥B / ⌃⌥N) |
| Automation · **Integrations** | Outbound event hooks fired when a meeting finishes. **Local script hook** (**off**) — run an executable with the event JSON on stdin; **Outgoing webhook** (**off**) — HTTPS POST the event JSON to a URL. Payload is note metadata only (title, date, type, linked org/project, tags — never audio), redacted per your Privacy settings, and both are suppressed in Local-only mode. Includes a live payload preview |
| Account · **Usage & Cost** | Local usage counters — dictations, words, meetings, time — plus an editable-price Groq **cost estimate** (month-to-date and all-time, audio transcribed, LLM tokens), an optional **monthly budget** (0 = off) with a spend bar and over-budget warning, all with their own reset; **Maintenance** — clear the **AI summary cache** (note briefs + follow-up drafts; shows the cached entry count) and set its **cache limit** (**500** entries) |
| System · **Diagnostics** | Error notifications toggle (**on**) and a list of recent failures with a clear button |
| Account · **About** | Version and build, description, privacy note |

All values are stored in `UserDefaults` (start-at-login lives in macOS Login Items) and take effect immediately — model and hotkey changes apply to the very next request/keypress, no restart needed. Every control has a per-item reset, plus a global "Reset All Settings".
